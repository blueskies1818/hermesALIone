Apple / macOS skills — tools that interact with the Mac desktop (Finder,
native apps) or system features (accessibility, screenshots).

The macOS-only skills that previously lived here (apple-notes, apple-reminders,
findmy, imessage, macos-computer-use) were removed because they require
proprietary Apple APIs, apps, or CLIs with no cross-platform fallback.
Replacements that work across Linux, macOS, and Windows are welcome.
